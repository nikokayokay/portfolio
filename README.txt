NIKOLI MCSURLEY PORTFOLIO
─────────────────────────

QUICK START (Mac)
─────────────────
1. Unzip the portfolio folder anywhere on your Mac
2. Double-click "serve.sh"
   — A terminal window opens
   — Your browser opens automatically at http://localhost:3000
   — Navigate the full site as normal

If double-clicking doesn't work:
1. Open Terminal
2. Drag "serve.sh" into the Terminal window and press Enter

To stop the server: press Ctrl + C in the terminal window

─────────────────────────
UPDATING A PAGE
─────────────────────────
1. Edit the .html file in any text editor (TextEdit, VS Code, etc.)
2. Save the file
3. Refresh the browser — changes appear immediately
   (no rebuild, no compile step required)

─────────────────────────
DEPLOYING
─────────────────────────
Upload the entire folder contents to any static host:
— Netlify: drag the folder onto netlify.com/drop
— GitHub Pages: push to a repo, enable Pages in Settings
— Vercel: import the repo or drag-drop the folder
